## 목적

리깅된 캐릭터의 애니메이션 키프레임을 생성하는 블렌더 애드온 기능을 구현하고 싶어.

애드온의 이름은 "CatAni"야.

### **기술적 구현 파이프라인**

1.  **표준 본 네이밍 및 리깅 매핑 (Blender Python API)**


*   `Rigify`나 Mixamo 등에서 사용하는 보편적인 본 매핑 데이터베이스를 구축합니다.

*   애드온이 씬 내 캐릭터의 본 구조(spine, hand, IK target, Pole target 등)를 탐색하여 AI가 이해할 수 있는 인덱스로 매핑(Retargeting)합니다.


1.  **AI 애니메이션 생성**

    *   LLM이 직접 키프레임 좌표를 매 프레임 찍는 방식은 오차가 커서 실용성이 떨어진다는데, 대신 **텍스트/모션 기반 AI 파이프라인**을 로컬 서버나 외부 API 형태로 연동하는 방식을 사용하면 된다고 해. 하지만 유료 버전의 외부 API를 사용하기는 어려워. 현재 사용 가능한건 Claude CLI, Codex CLI, Gemini API, OpenAI API정도야.

    *   **Motion Diffusion Model (MDM)**, **MDM-based Text-to-Motion**, 혹은 **HY-Motion** 같은 최신 AI 모델에 텍스트 프롬프트("sad walking", "happy idle")를 입력하여 3D 모션 데이터(BVH 또는 Transform 좌표)를 생성할 수 있다는데, 이게 무료로 활용할 수 있는 거라면 좋겠지만, 기왕이면 자체적으로 구축하고 싶어.

2.  **키프레임 적용 및 IK/FK 변환 (Blender** `bpy`**)**

    *   AI 모델이 생성한 회전/위치 좌표 데이터를 파이썬 API(`bpy.context.object.keyframe_insert`)를 통해 캐릭터의 IK/FK 컨트롤러 키프레임으로 변환하여 주입합니다.


**개발 방식 및 접근 전략**

*   **구현 방식 A: 외부 모션 생성 API / AI 모델 연동 (추천)**

    *   외부 AI 모션 라이브러리(또는 로컬 Python 서빙)를 두고, 애드온은 **"프롬프트 전달 -> 3D Pose 데이터 수신 -> 블렌더 본 키프레임 적용"** 역할만 수행합니다.

    *   개발 난이도가 가장 낮고 애니메이션 퀄리티가 높습니다.

*   **구현 방식 B: 사전 학습된 포즈 DB + LLM 보정**

    *   모션캡처 데이터베이스(AMASS 등)를 애드온 내에 구축하고, LLM이 텍스트 요청에 맞춰 포즈를 조합하고 IK 목표 위치를 보정해주는 방식입니다.


**실제 개발 시 고려해야 할 도전 과제**

*   **신체 비율 차이 (Proportion Issue):** AI가 만든 모션이 캐릭터의 신체 비율(팔 길이, 다리 길이 등)과 맞지 않아 발이 땅에 묻히거나 떠 있는 현상이 발생할 수 있어, 애드온 단에서 **IK Grounding / Post-processing** 처리가 필요합니다.

*   **성능 및 연산:** AI 모델을 로컬 Python 환경에서 직접 실행할 경우 블렌더 내 파이썬 환경과 딥러닝 라이브러리(PyTorch 등) 충돌 위험이 있으므로, 별도의 백엔드 프로세스로 분리 후 통신(REST API 또는 WebSocket)하는 구조가 안전합니다.


결론적으로 **‘표준 네이밍 매핑 + AI 모션 생성 + IK 키프레임 주입’** 파이프라인으로 충분히 개발 가능한 실용적인 프로젝트입니다.
